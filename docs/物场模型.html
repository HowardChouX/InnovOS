📖 物-场建模 使用指南

  1. 问题描述：填写问题名称、技术系统、期望功能与问题现象。
  2. 要素识别：填写 S1（被作用对象）、S2（工具/作用物）、F（场/作用方式）。
  3. 模型判断：选择 不完整 / 效应不足 / 有害 / 过度 / 需优化 模型；右侧实时生成物场三角形图。
  4. 解决策略：系统按模型类型给出 TRIZ 标准解决方向，勾选后可编辑具体方案文本；勾选含 S3/F2 的策略时，图中自动画出新物质/新场。
  5. 方案评估：将方案加入候选列表，按 效果/可行性/成本 打分，自动推荐最高分方案。
  6. 报告输出：一键生成标准物场分析报告，可复制或下载 .md 文件。
